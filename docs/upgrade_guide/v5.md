# Upgrading from v4 to v5

pinact v5 is built with [spf13/cobra](https://github.com/spf13/cobra) instead of
[urfave/cli](https://github.com/urfave/cli). The commands, the flags, and their behavior are
unchanged, but a long flag must now be written with two dashes.

## What this fixes

Two urfave/cli bugs no longer apply:

- A workflow file named `help` could not be passed to `pinact run`: the argument was taken as a
  request for the help of `run`.
- Pressing TAB after a `--` ran the command instead of completing it
  ([urfave/cli#1993](https://github.com/urfave/cli/issues/1993)). Since `pinact run` fixes files by
  default, a TAB pressed while typing a `pinact run --` command line rewrote the workflow files.
  cobra completes through a separate hidden command that never reaches the action.

## Long flags need two dashes

urfave/cli accepted a long flag with a single dash. cobra's flag parser does not: a single dash
introduces short flags, so `-check` means the short flags `-c -h -e -c -k`.

```sh
# v4
pinact run -check
pinact run -fix=false -no-api
pinact run -diff-file diff.txt

# v5
pinact run --check
pinact run --fix=false --no-api
pinact run --diff-file diff.txt
```

This matters most for `-check` and `-config`: `-c` is the short flag of `--config`, so `-check`
would otherwise be read as `--config=heck` and pinact would silently look for a configuration file
named `heck`. To prevent that, pinact rejects a single-dash long flag with an error naming the form
to use:

```console
$ pinact run -check
unknown flag: -check. Long flags need two dashes since pinact v5: --check
```

Short flags are unchanged, and can still be written with a single dash:

```sh
pinact run -u -m 7
pinact run -i "^actions/.*$" -e "^actions/checkout$"
pinact init -g
pinact -c pinact.yaml run
```

`--verify` and `--sep` also keep working, as aliases of `--verify-comment` and `--separator`.

## The Go module path is `pinact/v5`

Only for those importing pinact as a library, or installing it with `go install`:

```sh
go install github.com/suzuki-shunsuke/pinact/v5/cmd/pinact@latest
```
