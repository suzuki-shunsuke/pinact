# Upgrading from v3 to v4

## `--review` was removed

Options `--review`, `--repo-owner`, `--repo-name`, `--pr`, and `--sha` were removed.
Please use SARIF output piped to reviewdog instead.

```sh
pinact run --format sarif |
  reviewdog -f sarif -name pinact -reporter github-pr-review
```
